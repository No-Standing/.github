# Contributing

1. Create a branch from `main`. Don't commit directly to `main`.
2. Keep each change small and focused, and describe it clearly in the pull request.
3. Open a pull request using the template and complete every section.
4. Never commit secrets, credentials, tokens or private keys. Keep them in an approved secrets manager.
5. Wait for review from a code owner before merging.

Report security issues as described in [SECURITY.md](SECURITY.md), not in public issues.
